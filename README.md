# BRAND Libya Telegram Bot 🇱🇾

بوت تلجرام لعرض حسابات PUBG المنشورة في قناة، والبحث عنها، وعرض أسعار الشحن، وتقييم الخدمة، ولوحة تحكم خاصة بالمالك.

## الملفات
- `index.js` — كود البوت.
- `package.json` — الاعتماديات وأمر التشغيل.
- `brand-data.json` — يُنشأ تلقائيًا عند حفظ أول بيانات.

## الإعداد
اضبط متغيرات البيئة التالية في الاستضافة:
- `BOT_TOKEN` — توكن البوت من BotFather (سرّي).
- `OWNER_ID` — رقم Telegram ID للمالك؛ الافتراضي `7923337516`.
- `CHANNEL_USERNAME` — اسم القناة بدون @؛ الافتراضي `Pubg_Libya_Store`.
- `DATA_FILE` — اختياري، مسار ملف البيانات على قرص دائم.

ثم شغّل:
```bash
npm install
npm start
```

## ربط القناة
1. أضف البوت إلى قناة `Pubg_Libya_Store` بصلاحيات إدارية تسمح له بإدارة المنشورات/تعديلها عند الحاجة.
2. تأكد أن اسم المستخدم العام للقناة مطابق لقيمة `CHANNEL_USERNAME`.
3. انشر حسابًا يحتوي نصه على كلمة «ببجي» أو `PUBG`، وإذا كانت معه صور فالأفضل نشرها كألبوم واحد.
4. افتح البوت واستخدم «🔥 آخر الحسابات» أو ابحث برقم مثل `#001`.

## لوحة المالك
- افتح محادثة خاصة مع البوت.
- أرسل `/admin` أو اضغط زر «⚙️ لوحة تحكم المالك».
- يمكن تعديل الرسائل وأسماء الأزرار وجهات التواصل، وعرض الحسابات وحذفها من قاعدة بيانات البوت، ومراجعة التقييمات.

## تنبيه مهم عن التخزين
الكود يستخدم ملف JSON محليًا. بعض الاستضافات المؤقتة تمسح الملفات عند إعادة التشغيل أو إعادة النشر. استخدم استضافة بقرص دائم، أو انقل التخزين إلى قاعدة بيانات دائمة. احتفظ بنسخة احتياطية من `brand-data.json`.

## الأمان
- لا تضع `BOT_TOKEN` داخل الكود ولا ترفعه إلى GitHub.
- استخدم Secrets / Environment Variables في الاستضافة.
- لا تشغّل نسختين من البوت بالتوكن نفسه في وضع polling في الوقت نفسه.
- اختبر الوظائف في قناة/بوت تجريبي قبل الاعتماد التجاري.

## حدود النسخة
- استقبال الحسابات من القناة يتطلب أن تكون منشورات القناة ظاهرة للبوت كـ `channel_post`.
- حذف الحساب من لوحة التحكم يحذفه من بيانات البوت فقط، ولا يحذف المنشور الأصلي من القناة.
- صور الحساب تُحفظ كـ Telegram `file_id`، لا كملفات صور محلية.
